# 🚀 C++ untuk Competitive Programming (Interactive Learning Web)

Platform pembelajaran interaktif berbasis web yang dirancang khusus untuk membantu mahasiswa dan pemula memahami konsep dasar hingga menengah **C++ untuk Competitive Programming (CP)** melalui animasi langkah demi langkah, analogi dunia nyata, simulasi interaktif, dan latihan koding terarah.

Dibuat murni menggunakan **Vanilla HTML, CSS, dan JavaScript** tanpa dependensi eksternal, sehingga dapat langsung dibuka secara **100% offline** maupun di-host melalui GitHub Pages.

---

## 📚 Daftar Modul Lengkap (8 Modul)

1. **Modul 1: `vector` (Array Dinamis)**
   - *Analogi*: Rak buku ajaib yang memanjang otomatis saat `push_back`.
   - *Fitur*: Simulasi visual rak, kapasitas vs ukuran, lab interaktif `push_back`/`pop_back`.
2. **Modul 2: Fast I/O (`cin`, `cout` & `ios::sync_with_stdio`)**
   - *Analogi*: 🛵 Kurir motor bolak-balik (`endl`, TLE) vs 🚚 Truk kontainer buffer (`\n`, Accepted).
   - *Fitur*: Lab balapan benchmark 100.000 data secara real-time.
3. **Modul 3: Array 2D & Matriks**
   - *Analogi*: Lemari berpetak koordinat `[baris][kolom]` & trik 3 gelas swap dengan `temp`.
   - *Fitur*: Lab rotasi matriks interaktif 90 derajat searah jarum jam.
4. **Modul 4: `sort` & Lambda**
   - *Analogi*: Barisan murid tinggi badan & kartu instruksi wasit `[](auto a, auto b)`.
   - *Fitur*: Lab kustomisasi urutan ascending, descending, dan ganjil-genap.
5. **Modul 5: `pair` & `struct`**
   - *Analogi*: 🍔🥤 Paket combo burger-minuman (`.first`, `.second`) & form profil karakter RPG.
   - *Fitur*: Lab leaderboard multikriteria dan resolusi *tie-breaker*.
6. **Modul 6: `map` & `set`**
   - *Analogi*: 👑 Buku tamu VIP tanpa duplikat (`set`) & 📖 Kamus frekuensi telepon (`map`).
   - *Fitur*: Lab filter elemen unik dan penghitung frekuensi kata $O(\log N)$.
7. **Modul 7: `queue`, `stack`, dan `priority_queue`**
   - *Analogi*: 🎟️ Loket bioskop (FIFO), 🥞 Tumpukan piring (LIFO), dan 🏥 Pasien kritis IGD (Max/Min-Heap).
   - *Fitur*: Lab simulasi live 3 kontainer dan tantangan kurung seimbang (*Balanced Parentheses*).
8. **Modul 8: Template CP & `typename T`**
   - *Analogi*: 🖨️ Formulir surat resmi boilerplate CP & 🧇 Cetakan wafel serbaguna generic template.
   - *Fitur*: Generator boilerplate siap pakai dengan tombol salin otomatis & penguji fungsi generik.

## ✨ Fitur Unggulan

- **Analogi Kehidupan Nyata**: Setiap konsep abstrak diterjemahkan ke perumpamaan sehari-hari yang mudah dipahami orang awam.
- **Animasi Visual Tiap Baris**: Baris kode disorot bersamaan dengan perpindahan data di memori secara real-time.
- **Interactive Sandbox per Modul**: Tempat bermain dan bereksperimen langsung dengan data sebelum masuk ke soal.
- **Latihan Interaktif**:
  - 3 Soal Pilihan Ganda dengan umpan balik instan & alasan penjelasan.
  - 1 Soal Tebak Output Kode.
  - 1 Soal Mini Coding Challenge lengkap dengan validator **"Cek Solusi Saya"** dan kunci jawaban referensi.
- **Mode Gelap / Terang (Dark & Light Mode)**.
- **Desain Responsif**: Nyaman dibuka dari HP (360px) hingga monitor desktop.
- **Penyimpanan Progres**: Otomatis menyimpan progres belajar di `localStorage` per peramban.

## 🖥️ Cara Menjalankan

### Cara 1: Langsung Buka File (Offline)
Cukup klik dua kali file `index.html` atau `cpp-cp-belajar.html` di komputer atau HP Anda. Tidak memerlukan instalasi server atau koneksi internet.

### Cara 2: Akses via GitHub Pages
Aktifkan **GitHub Pages** di repositori ini (`Settings` -> `Pages` -> pilih branch `main`), lalu buka URL yang disediakan oleh GitHub.
